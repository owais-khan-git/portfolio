# Portfolio

My personal portfolio site — built with plain HTML/CSS and deployed with GitHub Pages.

**Live site:** https://owais-khan-git.github.io/portfolio/

## About

This is my first Git/GitHub project, built to learn the core workflow:
cloning, committing, pushing, and deploying. It's a simple one-page site
covering who I am, my skills, and how to get in touch.

## Built with

- HTML5
- CSS3
- GitHub Pages (hosting)

## Running locally

Clone the repo and open `index.html` in a browser, no build step needed.

```bash
git clone https://github.com/owais-khan-git/portfolio.git
cd portfolio
open index.html
```
